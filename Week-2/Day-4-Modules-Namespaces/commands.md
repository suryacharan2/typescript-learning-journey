# Commands Used - Day 4 (Week 2)

| Command | Explanation |
|---------|-------------|
| `npx ts-node examples.ts` | Runs the examples file directly |
| `tsc --module commonjs` | Compiles modules to the CommonJS format, used by Node.js |
| `tsc --module esnext` | Compiles modules to native ES module syntax, used for modern bundlers/browsers |
